JWT · JSON Web Token

Três partes. Uma assinatura.

Clique nos componentes para inspecionar Header, Payload e Signature. O conteúdo é decodificável: assinatura não é criptografia.

Tratamento de exceções

Erros também precisam explicar.

200

OK

Consulta realizada com sucesso.

201

Created

Livro cadastrado com sucesso.

400

Bad Request

Dados inválidos ou insuficientes.

401

Unauthorized

Token ausente, inválido ou expirado.

403

Forbidden

Identidade válida, mas sem permissão.

404

Not Found

Recurso solicitado não encontrado.

409

Conflict

Conflito com o estado atual do recurso.

500

Internal Server Error

Falha inesperada no processamento.

Boas práticas: uma API real precisa proteger endpoints no servidor, verificar assinatura e expiração de tokens, limitar informações de erro e registrar eventos de forma segura.
