A segurança de verdade

Uma simulação não é um servidor protegido.

Na página estática

As regras, os usuários e os endpoints são simulados no próprio navegador para facilitar a aprendizagem. Um JWT assinado na página demonstra a estrutura e a validação, mas a chave de exemplo é visível no código, portanto não oferece proteção real.

Em uma API real

O servidor verifica tokens e permissões a cada requisição, guarda segredos fora do código público, protege credenciais e aplica regras de acesso. Incluímos um exemplo opcional em Python/FastAPI dentro do pacote.

Importante: use apenas contas, senhas e tokens fictícios. Nunca cole credenciais reais neste laboratório ou em ferramentas públicas de decodificação.
